# 단가 관리

단가표 조회, 단가 변경 이력 기록·검색·분석, 마진 계산을 하는 웹앱입니다. PC 화면(`pc.html`)과 핸드폰 화면(`mobile.html`)이 따로 있고, 데이터는 **본인 구글 드라이브**에만 저장됩니다.

> 이 저장소에는 단가 데이터가 들어 있지 않습니다. 단가는 앱에서 `단가.xlsx`를 가져와 드라이브에 저장합니다.

## 주소

- 시작: `https://1000dayago.github.io/danga/` (기기에 맞는 화면으로 자동 이동)
- PC: `https://1000dayago.github.io/danga/pc.html`
- 핸드폰: `https://1000dayago.github.io/danga/mobile.html`
- 화면 다시 고르기: `https://1000dayago.github.io/danga/?choose`

## 처음 한 번 설정 (약 10분)

드라이브에 저장하려면 구글에 "이 앱이 내 드라이브를 써도 된다"는 등록이 필요합니다. 본인 계정으로 한 번만 하면 됩니다.

### 1. 프로젝트 만들기
1. https://console.cloud.google.com 접속 (단가 데이터를 저장할 구글 계정으로 로그인)
2. 위쪽 프로젝트 선택 → **새 프로젝트** → 이름 `danga` → 만들기

### 2. Google Drive API 켜기
1. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**
2. `Google Drive API` 검색 → **사용**

### 3. 동의 화면 설정
1. **API 및 서비스 → OAuth 동의 화면** (또는 **Google 인증 플랫폼**)
2. 시작하기 → 앱 이름 `단가 관리`, 지원 이메일은 본인 메일
3. 대상: **외부**
4. **대상(테스트 사용자)** 에 본인 Gmail 주소 추가 → 저장

### 4. 클라이언트 ID 만들기
1. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   (또는 Google 인증 플랫폼 → **클라이언트 → 클라이언트 만들기**)
2. 애플리케이션 유형: **웹 애플리케이션**
3. **승인된 JavaScript 원본** 에 추가: `https://1000dayago.github.io`
4. 만들기 → 나오는 **클라이언트 ID** (`…apps.googleusercontent.com`) 복사

### 5. 앱에 입력
1. 앱의 **저장 · 설정** (핸드폰은 **설정** 탭) → **구글 클라이언트 ID** 칸에 붙여넣기
2. **저장 폴더 경로** 확인 (기본값 `회사 폴더/단가관리`)
3. **이 기기에서 파일 선택** 으로 `단가.xlsx`를 가져오고 → **이 데이터로 시작**
4. **드라이브에 저장** → 구글 로그인 창에서 허용

로그인할 때 "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → 단가 관리(으)로 이동**을 누르면 됩니다. 본인이 만든 앱이라 나오는 안내입니다.

핸드폰에서도 5번의 클라이언트 ID만 한 번 입력하면 됩니다(엑셀 가져오기는 필요 없음). **최신본 불러오기**를 누르면 PC에서 저장한 내용이 나옵니다.

## 앱처럼 쓰기 (홈 화면에 추가)

- **아이폰 (Safari)**: 공유 버튼 → **홈 화면에 추가**
- **안드로이드 (Chrome)**: 메뉴 ⋮ → **홈 화면에 추가** 또는 **앱 설치**
- **PC (Chrome·Edge)**: 주소창 오른쪽 설치 아이콘 → **설치**

## 저장 방식

- 드라이브의 `회사 폴더/단가관리/단가DB.json` 파일 하나를 계속 갱신합니다.
- 하루 한 번 `단가관리/백업/단가DB_날짜.json` 사본을 남깁니다. **저장 기록 · 백업 → 목록 보기**에서 예전 상태로 되돌릴 수 있습니다.
- PC와 핸드폰에서 각각 입력해도 저장할 때 서로의 변경을 합칩니다. 한쪽에서 지운 기록은 다른 쪽에서도 지워집니다.
- 저장 전 입력은 그 기기 브라우저에 임시 보관되고, 화면 위에 "저장 안 된 변경 N건"으로 표시됩니다.
- 구글 로그인은 약 1시간 유지됩니다. 그 뒤 저장하면 로그인 창이 다시 뜹니다.

## 엑셀로 단가 일괄 변경

1. **전체 단가표 → 엑셀 일괄 변경** (핸드폰: 설정 → 내보내기) → **양식 내려받기**
2. 엑셀의 `단가입력` 시트에서 바꿀 칸만 고칩니다. 외화는 `3.9 EUR`, `1.3 RMB`처럼 적고, 새 품목은 맨 아래 행에 추가합니다.
3. **파일 선택**으로 올리면 바뀐 칸만 미리 보여 줍니다. 칸마다 빼거나 넣을 수 있습니다.
4. 적용일과 사유를 정하고 **반영하기** → **드라이브에 저장**

빈칸은 "변경 없음"으로 처리되고, 모르는 거래처 열이나 숫자가 아닌 값은 반영하지 않고 알려 줍니다.

## 품목 · 거래처 수정과 삭제

- **품목**: PC는 단가표의 MODEL 칸, 핸드폰은 품목 화면의 **품목 수정 · 삭제**. 모델 이름 변경, 다른 대구분·소구분으로 이동, 삭제.
- **거래처**: PC는 단가표의 거래처 머리글, 또는 **품목 · 거래처 관리**. 이름 변경, 매입·판매 변경, 삭제.
- **대구분 · 소구분 이름**: **품목 · 거래처 관리**에서 바꾸면 그 구분의 품목이 모두 바뀝니다. 있는 이름으로 바꾸면 합쳐집니다.
- 삭제한 품목·거래처의 단가와 이력은 보관되고, 관리 화면에서 **복원**할 수 있습니다. 변경 내용은 **관리 기록**에 남습니다.

## 화면 구성

- **홈**: 저장 상태, 역마진·저마진 칸 수, 적용 예정 단가를 한눈에 보고, 자주 쓰는 작업과 최근 변경으로 바로 갑니다. 카드를 누르면 목록이 펼쳐집니다.
- **단가표**(핸드폰은 단가 탭): 기준일의 전체 단가. 외화 단가는 **원래 통화 / 원화 환산**으로 바꿔 볼 수 있습니다.
- **이력**: 변경 내역 검색.
- **분석**: 변경 비교 · **거래처 비교**(같은 모델의 최저·평균·최고, 매입처 비교) · **적용 예정 단가**.
- **마진 · 환율**: 마진표 · **원가 변동 시뮬레이션** · 환율.
- **작업 도구**(핸드폰은 더보기 → 도구): 단가 찾아서 바꾸기, 품목 추가, 엑셀 일괄 변경, **비율 인상·인하**, **거래처별 단가표**, 내보내기.
- **품목 · 거래처**, **설정**.

## 거래처 그룹

**품목 · 거래처** 화면에서 "삼성 그룹"처럼 관련 거래처를 묶습니다(이름이 비슷한 거래처는 자동으로 제안합니다). 그룹은 선택을 편하게 하는 묶음일 뿐이라 단가 데이터는 거래처별로 그대로입니다.
비율 인상·인하, 거래처별 단가표, 이력 검색, 변경 비교, 거래처 비교, 추이 비교, 시뮬레이션, 단가표 열 보기에서 그룹 이름 하나로 소속 거래처를 한 번에 고릅니다.

## 영업용 읽기 전용 공유

영업 담당자에게 **매입가와 마진 없이 판매 단가만** 보여 줄 수 있습니다.

1. 관리자: **설정 → 영업용 공유**에서 폴더(예: `회사 폴더/단가관리/영업용`)를 정하고 **영업용 파일 저장**을 누릅니다. 매입처 열, 사유·비고, 입력자, 관리 기록은 파일에 들어가지 않습니다. "드라이브에 저장할 때 함께 갱신"을 켜면 저장할 때마다 자동으로 갱신됩니다.
2. 드라이브에서 그 폴더를 담당자 구글 계정에 **보기 권한**으로 공유합니다(이 폴더만 공유하세요). 담당자 계정은 Google Cloud의 **테스트 사용자**에도 추가해야 합니다.
3. 담당자: 앱을 열고 **설정 → "이 기기를 영업용으로 전환"**(관리자가 먼저 전환해 주거나, 일반 설정에서 전환) 후 클라이언트 ID와 폴더 링크를 입력하고 **최신본 불러오기**를 누릅니다.

영업용 모드는 단가표, 변경 이력(가격만), 거래처별 단가표, 내보내기만 쓸 수 있고, 구글에는 읽기 전용(`drive.readonly`) 권한만 요청합니다.

## 정렬 · 순서 바꾸기 · 고정

- **정렬**: 단가표의 대구분·소구분·MODEL 머리글을 누르면 ▲ → ▼ → 해제 순서로 바뀝니다(핸드폰은 "정렬" 선택). 숫자가 든 이름은 크기 순으로 정렬합니다. 화면에서만 바뀌고 저장된 순서는 그대로이며, **정렬을 순서로 저장**을 누르면 지금 정렬이 실제 순서가 됩니다(되돌리기 가능).
- **순서 바꾸기**: **순서 바꾸기** 버튼을 켜면 PC는 ⠿ 손잡이를 끌어서, PC와 핸드폰 모두 ▲▼ 버튼으로 옮깁니다. 품목은 같은 소구분 안에서, 소구분은 같은 대구분 안에서, 대구분은 전체에서 움직이고, 다른 구분으로 옮기려면 품목 수정을 쓰세요. 순서는 드라이브에 저장되어 모든 기기가 같고, 두 기기에서 동시에 바꾸면 나중에 바꾼 쪽이 반영됩니다.
- **고정**: 품목의 핀(핸드폰은 품목 화면의 "맨 위에 고정")이나 대구분의 핀을 누르면 정렬·검색을 해도 맨 위에 모아 보입니다. 고정은 **기기별 설정**입니다. "고정한 것만 보기"로 모아 볼 수 있습니다.
- 설정의 "새 품목을 모델 이름 순서에 맞게 끼워 넣기"를 켜면 새 품목이 같은 소구분의 이름 순서 위치에 들어갑니다(끄면 맨 아래).
- 영업용 모드에서도 정렬과 고정은 쓸 수 있습니다(순서 바꾸기·저장은 제외).

## 알아 둘 기능

- **인상 예약**: 비율 인상·엑셀 일괄 변경에서 적용일을 미래로 정하면 예약으로 기록되고, 적용일이 되면 단가표에 자동 반영됩니다(분석 → 적용 예정 단가에서 확인·취소). 적용일 빠른 선택(내일, 다음 달 1일, 다음 분기 1일, 내년 1월 1일)이 있습니다.
- **단가표 발행 기록**: 거래처별 단가표를 만들면 기록이 남고(작업 도구), "다시 만들기"로 그때 조건 그대로 열립니다.
- **저장 전 역마진 예측**: 단가·환율을 바꾸기 전에 역마진이 새로 생기는 칸 수와 이름을 알려 줍니다.
- **추이 비교**: 분석 → 추이 비교에서 여러 거래처(또는 그룹)의 단가 변화를 한 그래프로 겹쳐 봅니다. "시작을 100으로" 옵션으로 상승률을 비교합니다.
- **수정 · 삭제 내역**: 이력 → 수정·삭제 내역에서 기록 수정, 기록 삭제, 이름 변경, 그룹 변경, 단가표 발행을 시간순으로 봅니다.

- **되돌리기**: 저장 전 변경을 한 단계씩 취소합니다(Ctrl+Z). 일괄 변경은 한 번에 되돌립니다. 저장하면 이전 단계는 비워집니다.
- **큰 변동 경고**: 기존보다 설정한 비율(기본 30%) 이상 달라지거나 통화가 바뀌면 한 번 더 확인합니다.
- **저마진 기준**: 설정에서 바꿉니다(기본 10%). 단가를 기록한 뒤 그 품목의 역마진·저마진을 알려 줍니다.
- **통화**: 원, USD, EUR, RMB, JPY가 위에 나오고, "다른 통화 검색…"으로 세계 통화 약 110개를 코드나 이름으로 찾습니다. 환율은 모든 통화를 **1단위당 원**으로 입력하며, 단가를 입력한 통화는 환율 표에 자동으로 칸이 생깁니다.
- **기록 수정**: 이력에서 칸을 눌러 나오는 변경 이력의 **수정** 버튼으로 적용일, 단가, 통화, 사유, 비고를 고칩니다. 수정 내용은 "수정됨"으로 남고, 두 기기에서 고쳤을 때는 나중에 고친 쪽이 반영됩니다. 기준 단가는 수정할 수 없습니다.
- **일괄 변경 묶음**: **이력 → 일괄 변경 묶음**에서 비율 인상·엑셀 일괄 변경·품목 추가로 한 번에 들어간 기록을 묶어 보고, 선택한 기록의 적용일을 한꺼번에 바꾸거나 지웁니다. 이 기능 이전에 입력한 기록은 입력 시각·사유·비고가 같은 것을 "추정"으로 묶습니다.
- **입력자**: 구글 계정 이름이 이력에 남습니다(설정에서 변경 가능).
- **즐겨찾기**(핸드폰): 품목 화면의 ☆.
- **단축키**(PC): Ctrl+S 저장, Ctrl+Z 되돌리기, / 검색.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 기기에 맞는 화면으로 이동 |
