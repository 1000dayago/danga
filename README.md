# 단가 관리

단가표 조회, 단가 변경 이력 기록·검색·분석, 마진 계산을 하는 웹앱입니다. PC 화면(`pc.html`)과 핸드폰 화면(`mobile.html`)이 따로 있고, 데이터는 **본인 구글 드라이브**에만 저장됩니다.

> 이 저장소에는 단가 데이터가 들어 있지 않습니다. 단가는 앱에서 `단가.xlsx`를 가져와 드라이브에 저장합니다.

## 주소

- 시작: `https://1000dayago.github.io/danga/` (기기에 맞는 화면으로 자동 이동)
- PC: `https://1000dayago.github.io/danga/pc.html`
- 핸드폰: `https://1000dayago.github.io/danga/mobile.html`
- 화면 다시 고르기: `https://1000dayago.github.io/danga/?choose`

## 처음 한 번 설정 (약 10분)

드라이브에 저장하려면 구글에 "이 앱이 내 드라이브를 써도 된다"는 등록이 필요합니다. 본인 계정으로 한 번만 하면 됩니다.

### 1. 프로젝트 만들기
1. https://console.cloud.google.com 접속 (단가 데이터를 저장할 구글 계정으로 로그인)
2. 위쪽 프로젝트 선택 → **새 프로젝트** → 이름 `danga` → 만들기

### 2. Google Drive API 켜기
1. 왼쪽 메뉴 **API 및 서비스 → 라이브러리**
2. `Google Drive API` 검색 → **사용**

### 3. 동의 화면 설정
1. **API 및 서비스 → OAuth 동의 화면** (또는 **Google 인증 플랫폼**)
2. 시작하기 → 앱 이름 `단가 관리`, 지원 이메일은 본인 메일
3. 대상: **외부**
4. **대상(테스트 사용자)** 에 본인 Gmail 주소 추가 → 저장

### 4. 클라이언트 ID 만들기
1. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   (또는 Google 인증 플랫폼 → **클라이언트 → 클라이언트 만들기**)
2. 애플리케이션 유형: **웹 애플리케이션**
3. **승인된 JavaScript 원본** 에 추가: `https://1000dayago.github.io`
4. 만들기 → 나오는 **클라이언트 ID** (`…apps.googleusercontent.com`) 복사

### 5. 앱에 입력
1. 앱의 **저장 · 설정** (핸드폰은 **설정** 탭) → **구글 클라이언트 ID** 칸에 붙여넣기
2. **저장 폴더 경로** 확인 (기본값 `회사 폴더/단가관리`)
3. **이 기기에서 파일 선택** 으로 `단가.xlsx`를 가져오고 → **이 데이터로 시작**
4. **드라이브에 저장** → 구글 로그인 창에서 허용

로그인할 때 "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → 단가 관리(으)로 이동**을 누르면 됩니다. 본인이 만든 앱이라 나오는 안내입니다.

핸드폰에서도 5번의 클라이언트 ID만 한 번 입력하면 됩니다(엑셀 가져오기는 필요 없음). **최신본 불러오기**를 누르면 PC에서 저장한 내용이 나옵니다.

## 앱처럼 쓰기 (홈 화면에 추가)

- **아이폰 (Safari)**: 공유 버튼 → **홈 화면에 추가**
- **안드로이드 (Chrome)**: 메뉴 ⋮ → **홈 화면에 추가** 또는 **앱 설치**
- **PC (Chrome·Edge)**: 주소창 오른쪽 설치 아이콘 → **설치**

## 저장 방식

- 드라이브의 `회사 폴더/단가관리/단가DB.json` 파일 하나를 계속 갱신합니다.
- 하루 한 번 `단가관리/백업/단가DB_날짜.json` 사본을 남깁니다. **저장 기록 · 백업 → 목록 보기**에서 예전 상태로 되돌릴 수 있습니다.
- PC와 핸드폰에서 각각 입력해도 저장할 때 서로의 변경을 합칩니다. 한쪽에서 지운 기록은 다른 쪽에서도 지워집니다.
- 저장 전 입력은 그 기기 브라우저에 임시 보관되고, 화면 위에 "저장 안 된 변경 N건"으로 표시됩니다.
- 구글 로그인은 약 1시간 유지됩니다. 그 뒤 저장하면 로그인 창이 다시 뜹니다.

## 엑셀로 단가 일괄 변경

1. **전체 단가표 → 엑셀 일괄 변경** (핸드폰: 설정 → 내보내기) → **양식 내려받기**
2. 엑셀의 `단가입력` 시트에서 바꿀 칸만 고칩니다. 외화는 `3.9 EUR`, `1.3 RMB`처럼 적고, 새 품목은 맨 아래 행에 추가합니다.
3. **파일 선택**으로 올리면 바뀐 칸만 미리 보여 줍니다. 칸마다 빼거나 넣을 수 있습니다.
4. 적용일과 사유를 정하고 **반영하기** → **드라이브에 저장**

빈칸은 "변경 없음"으로 처리되고, 모르는 거래처 열이나 숫자가 아닌 값은 반영하지 않고 알려 줍니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 기기에 맞는 화면으로 이동 |
| `pc.html` | PC 화면: 엑셀식 전체 단가표, 이력, 분석, 마진 |
| `mobile.html` | 핸드폰 화면: 품목 목록 → 품목별 거래처 단가 |
| `core.js` | 공통 데이터 처리, 엑셀 가져오기, 구글 드라이브 저장 |
| `common.css` | 공통 디자인 |
| `sw.js`, `manifest.webmanifest`, `icons/` | 홈 화면 설치, 오프라인 열기 |
